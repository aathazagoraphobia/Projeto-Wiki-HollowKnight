# Projeto-Wiki-HollowKnight
Projeto de Wiki criado por fãs visando a disponibilidade de informações do jogo Hollow Knight

• João Victor Silva Meireles
• Rebeca de Araújo Carneiro

• João Paulo Jardim Ziviani
• Pedro Vitor Gonçalves Brasil
Objetivo Geral:
Desenvolver uma wiki voltada ao jogo Hollow Knight com o objetivo de ensinar e divulgar informações variadas sobre a interface do jogo, como também seu desenvolvimento e diversas curiosidades; visando o aprimoro da wiki com o feedback de visitantes através do formulário disponível dentro do site. 
O projeto possuirá:
• Front-end produzido com HTML e estilizado utilizando CSS e JS
• Validação de formulário a partir de JavaScript
• Link de ancoragens para a navegação da wiki a partir do nav encontrado no header
• Controle de versão com participação individual comprovada via Git/GitHub
